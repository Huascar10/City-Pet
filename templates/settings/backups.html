Respaldos Relacionales Completos y Restauración

Respaldo íntegro de las 16 tablas del sistema, archivos multimedia y verificación en base de datos aislada

1. Generar Respaldo Completo del Sistema

Incluye todas las tablas relacionales: usuarios, configuración, clientes, proveedores, productos, ventas, detalle de ventas, abonos, excepciones de crédito, compras, detalle de compras, pagos a proveedores, kardex de inventario, movimientos financieros, recibos, auditoría e imágenes/logos con firma criptográfica SHA-256.

2. Verificar Respaldo en Base de Datos de Prueba Aislada

Comprueba la firma SHA-256 y simula una restauración completa en una base de datos en memoria aislada sin tocar los datos reales.

3. Restaurar Sistema Completo desde Respaldo

Valida primero el archivo en una base de datos aislada, genera un respaldo automático previo en backups/ y restaura todas las tablas y relaciones sin pérdida de información.
